get /healthcheck
Health Check (apiHealthcheckGet)
Returns the health status of the server.

Return type

response_200_healthcheck

Example data

Content-Type: application/json
{
  "server_status" : "Running",
  "timestamp" : 1681234567
}

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

Server is running response_200_healthcheck 
get /v2/flights
Search Flights (apiV2FlightsGet)
Searches for flights based on departure and arrival airports and departure date.

Query parameters

departingFrom (required)
Query Parameter — The ICAO code of the departure airport.
arrivingTo (required)
Query Parameter — The ICAO code of the arrival airport.
departureDate (required)
Query Parameter — The departure date in <code>YYYYMMDD</code> format.

Return type

array[response_200_flights]

Example data

Content-Type: application/json
[ {
  "duration" : 180,
  "flight_number" : "SK001",
  "price" : 250,
  "origin" : "KMIA",
  "destination" : "SCEL",
  "departure" : "2025-04-12T14:30:00Z"
}, {
  "duration" : 180,
  "flight_number" : "SK001",
  "price" : 250,
  "origin" : "KMIA",
  "destination" : "SCEL",
  "departure" : "2025-04-12T14:30:00Z"
} ]

Produces

This API call produces the following media types according to the Accept request header; the media type will be conveyed by the Content-Type response header.
  • application/json

Responses

200

Flights found

400

Invalid request response_400

Unprocessable Entity response_422
